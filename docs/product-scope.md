# 제품 범위와 합의 사항

작성일: 2026-08-21

이 문서는 지금까지 대화에서 합의한 범위를 기록한다. 아직 결정하지 않은 항목은 임의로 확정하지 않는다.

## 1. 제품 성격

이 제품은 뉴스 사이트가 아니다. 사용자가 국제정세·정치·물리 정보를 수집하고, 서로 연결하고, 근거를 검토하고, AI와 함께 분석 결과를 개인 지식으로 축적하는 **분석 워크스페이스**다.

기본 원칙은 다음과 같다.

1. 속보보다 맥락과 근거를 우선한다.
2. 사실, 출처의 주장, AI의 추론, 불확실성을 화면에서 구분한다.
3. 초보자용 설명도 근거를 숨기지 않고, 고급 설명도 불필요한 전문용어로 포장하지 않는다.
4. 분야별 사용자 수준은 서로 독립적으로 설정한다.
5. 개인용으로 먼저 만들고 다중 사용자 기능은 구조적으로만 대비한다.

## 2. 국제정세

### 기본 화면

- 혼합형 상황실: 세계 지도 + 핵심 브리핑 + 사건 목록
- 한국을 주 관심축으로 두고 미국을 부 관심축으로 둔다.
- 나머지 국가는 한국·미국과의 관련성, 급격한 변화, 충격성, 이례성을 기준으로 노출한다.
- 기본 지도에는 영향도가 큰 최근 변화만 표시하고, 상세 레이어는 사용자가 켠다.

### 사건 분석 구조

사건 상세는 한 화면의 긴 AI 답변이 아니라 아래 단위로 분리한다.

- 한눈에 보는 브리핑
- 확인된 사실 / 아직 확인되지 않은 주장
- 지도와 시간순 변화
- 주요 행위자와 이해관계
- 직접 원인과 구조적 배경
- 한국 및 국제적 영향
- 가능한 시나리오와 각 시나리오의 조건
- 역사적 맥락
- 원문 출처와 추가로 읽을 자료
- 개인 분석 기록과 저장

### 긴급 브리핑

- 전 세계의 중대한 사건과 개인 관심 분야 경보를 결합한다.
- 단순히 기사 수가 많은 사건이 아니라 영향도, 변화 속도, 한국 관련성, 출처 신뢰도와 다양성을 함께 본다.
- AI가 만든 중요도 점수는 이유와 구성 요소를 공개해야 한다.

## 3. 정치

### 한국 — 주 화면

- 법안, 정부 정책, 국회 절차, 정당 및 주요 정치 행위자의 흐름
- 발표와 실제 제도 변화의 차이
- 정책이 누구에게 어떤 경로로 영향을 주는지
- 동일 사안을 둘러싼 서로 다른 주장과 근거

### 미국 — 부 화면

- 의회·행정부의 주요 변화
- 한국의 안보·경제·외교에 연결되는 사안
- 국내 정치 사건이 국제정세에 미치는 영향

### 기타 국가

- 한국 또는 미국과 직접 관련된 변화
- 정권·제도·정책의 급변
- 국제적으로 이례적이거나 파급력이 큰 사건

정치 탭은 인물 가십이나 진영별 기사 묶음보다 **제도, 결정 과정, 주장과 근거의 비교**를 중심으로 한다.

## 4. 물리

물리 탭은 시뮬레이션 중심이 아니다. 이해, 유도, 자료 탐색, 학습 기록을 중심으로 한다.

### 핵심 기능

1. 개념 심층 탐구
2. 수식의 구조와 단계별 유도
3. 실제 현상의 물리적 분석
4. 최신 연구 및 논문 탐색
5. 이론 간 관계와 전제 비교
6. 사고실험 분석
7. 개인 연구·학습 기록
8. 개인 물리 자료 보관소
9. 강의 자료·강의 영상·논문을 찾아주는 자료 탐색

### 개인 자료 보관소

- 파일 자체 업로드와 외부 링크·메타데이터 저장을 함께 지원하는 혼합형
- PDF, 이미지, 노트, 문제 풀이, 강의 링크, 논문 링크를 한 주제 아래 연결
- 원본, AI 요약, 사용자의 노트와 인용 위치를 분리해 보관
- 검색 결과는 업로드 자료와 외부 자료를 명확히 구분

### IPhO 하위 모듈

- 물리 탭의 부속 모듈로 둔다.
- KPhO·IPhO 준비를 처음 시작하는 단계부터 심화 단계까지 지원할 수 있어야 한다.
- 전체 물리 탭을 올림피아드 전용으로 만들지는 않는다.
- 향후 진단, 주제별 로드맵, 문제 풀이 기록, 오답 원인 분류, 제한 시간 훈련을 논의한다.

## 5. AI 분석 패널

- 별도 버튼이나 탭으로 호출할 때만 나타난다.
- 단순 텍스트 답변 외에 지도 강조, 타임라인, 표, 인과관계, 출처 카드 등 문제에 맞는 표현을 사용한다.
- 현재 보고 있는 사건·정책·물리 자료의 맥락을 분석 입력에 포함할 수 있다.
- 분석 결과에는 근거 링크, 인용 위치, 불확실성, 반대 설명을 포함한다.
- 사용자 수준에 따라 용어 설명, 수식 생략 정도, 유도 단계와 배경지식 링크를 조절한다.

## 6. 내장 캡처

사용자는 외부 스크린샷 앱 없이 다음 입력을 AI에 보낼 수 있어야 한다.

- 사이트 내부 카드나 지도 영역 선택
- 현재 브라우저 탭, 다른 탭, 창 또는 화면 공유 후 영역 선택
- 이미지·PDF 업로드
- URL과 선택 텍스트

브라우저 보안상 탭·창·화면 공유는 사용자가 매번 직접 선택하고 허용해야 한다. 사이트가 허가 없이 화면을 읽거나 영구 권한을 저장하는 방식은 범위에 포함하지 않는다.

## 7. 분야별 수준

사용자 수준은 분야마다 독립적으로 설정하며, 한 사람의 현재 수준이나 목표를 공개 제품 문서에 기록하지 않는다.

- 물리: 개념 이해, 수학적 구조, 유도 능력, 문제 해결 능력
- 정치: 제도 이해, 정책 비교, 주장과 근거 평가 능력
- 국제정세: 배경지식, 원자료 탐색, 출처 평가, 독립 분석 능력

수준은 고정 등급 하나로 판단하지 않는다. 개념 이해, 수학 전개, 출처 평가, 독립 분석과 같은 세부 축으로 나누는 방식은 추후 대화로 확정한다.

## 8. 아직 결정하지 않은 것

- 공식 제품명과 브랜드
- Cloudflare-first 추천안의 최종 채택 여부와 실제 리소스 구성
- AI 모델 공급자
- 로그인 방식과 외부 공개 시점
- 유료 기능과 운영 비용 정책
- 수준 진단 방식과 등급 명칭
- IPhO 모듈의 정확한 커리큘럼
- 첫 배포에서 지원할 데이터 소스의 최종 목록
